# BootCaptain Evidence Register

This register records the load-bearing claims reviewed on 2026-07-26. It is a
starting point, not a substitute for the Phase 0 fixture matrix in `PLAN.md`.

**Confidence meanings:**

- **High:** public Apple documentation, schema, or current man page directly
  supports the narrow claim.
- **Medium:** reproducible open-source code or credible independent observation
  supports it, but the behavior is private, version-sensitive, or incomplete.
- **Open:** the sources conflict or do not establish the claim; production code
  must not depend on it before hardware validation.

For every hardware result, add the macOS version and build, hardware/VM,
architecture, clean-install or upgrade origin, account/session type, management
state, SIP/FileVault/TCC state, commands/fixtures, expected result, actual
result, and captured artifacts.

The URLs below are dated research pointers. Mutable man-page mirrors and
repository branches must be pinned to the tested SDK, archive, or commit before
implementation relies on them. Evidence IDs are stable and may be cited from
`PLAN.md`; split an ID rather than broadening it to cover a materially different
claim.
